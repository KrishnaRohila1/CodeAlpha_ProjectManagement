# 🚀 CodeAlpha Project Management System

A web-based Project Management System developed as part of the CodeAlpha internship/project program. This application helps users manage projects, tasks, and related information efficiently.

## 📌 Features

- Create and manage projects
- Create and manage tasks
- User management
- Project tracking
- Task organization
- MongoDB database integration
- REST API support

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB
- Mongoose
